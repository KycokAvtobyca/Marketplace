Эта папка останется пустой, т.к. используется архитектурная методология FSD. Иначе при отсутсвии папки Next.js будет пытаться использовать src/pages в качестве Pages Router, даже если используется App Router, что приведёт к ошибкам при сборке проекта. Все основные слои FSD располагаются в папке src.
